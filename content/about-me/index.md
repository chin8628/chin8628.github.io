Check my bio at my homepage, [cloudian.in.th](https://cloudian.in.th/)

**Cloudian**, the website title and domain, is my old alias. I created it when I was in a junior high school. I've not used it since I graduated. It used to be "Cloudian Studio" because I was a volunteer photographer in a school. Time goes by, I stopped shooting a photo. So I only keep "Cloudian" as a title.

The name got an idea from "cloud", condensed water in the sky. I added -ian because I thought it was cool. And I've never regret it. It means freedom, roaming aimlessly without worry like a cloud in the sky.

Now, I only use it as my website's domain because I don't want to change it. I keep it because it feel like a legacy from the past.
