ช่วงนี้มีแค่เขียนรีวิว เนื่องจากไม่ค่อยอยากเขียนอะไรที่เป็นคหสต.มาก เดี๋ยวเป็นประเด็นอีก (ฮา) ก็เลยกะเอาเกมส์ที่เล่นมาเขียนละกัน เพราะรู้สึกว่าเกมส์นี้มันโดนใจมา เป็นเกมส์แนวมิวซิคเกมส์ กดๆๆตามจังหวะ คล้าย Thapster หรือพวก O2Jam แต่โดยความรู้สึกส่วนตัวคือเพลงมันเพราะกว่า และมันมีเนื้อเรื่องด้วย

{{< figure src="https://i.imgur.com/0q60WvL.png" >}}

รู้จักเกมส์นี้จริงๆเลยเพราะพี่คนนึงเขาโหลดมาเล่นแล้วเขียนบล็อก ผมก็เลยไปโหลดมาตาม ก็แบบ เพลงเพราะดีนะ โดยส่วนตัวเพลงที่ชอบที่สุดในเกมส์คือ Wing of Piano

{{< figure src="https://i.imgur.com/vne9eou.png" >}}

ตัวเกมส์จริงๆไม่ค่อยมีอะไรมาก คล้ายมิวซิคเกมส์ตัวอื่นๆ แต่ต่างกันจุดนึงคือคีย์ที่ให้กดปกติแล้วมันจะต้องถูกแบ่งช่องให้ตายตัว เช่น มีสี่ช่อง ห้าช่องให้กด แต่ของ Deemo นั้นมันไม่ได้ตายตัวเสมอว่าจะลงมาช่องนั้น เพราะมันจะไม่มีช่องให้ลง มันอยากลงตรงไหนมันก็ลงมาให้เรากดเลย แบบภาพด้านบน

อีกส่วนที่ชอบก็คือคีย์ที่ให้กดแต่ละตัวขนาดอาจจะไม่เท่ากัน เท่าที่สังเกตมามันเหมือนมีสามขนาด สั้น ปกติ ยาว แต่ละอันจะแทนเสียงต่างกันไป เช่นเล็ก็เสียงสูง อันยาวก็แทนเสียงทุ้มๆ มันให้ความรู้สึกเหมือนเรากำลังเล่นเพลงนั้นอยู่จริงๆเลย แล้วบางทีจะมีคีย์ชนิดที่สองโผล่มา ซึ่งอันนี้ผมไม่ได้แคปภาพมาด้วย มันจะออกสีขาวๆหน่อย จะแทนเสียงอื่นที่ที่ไม่ใช้เปียโน (ผมลองฟังๆดูเหมือนคีย์สีดำจะแทนเสียงของเปียโน แต่เพลงหลังๆเหมือนจะแทนเสียงเครื่องดนตรตัวอื่นด้วย)

{{< figure src="https://i.imgur.com/FEGLjal.png" >}}

เพลงตอนแรกถ้าจำไม่ผิดมีแค่เพลงเดียวเองมั้ง พอเราเล่นไปสักพักก็จะมีปลดล็อกเรื่อยๆ เหมือนเกมส์ทั่วไป ครับ หนึ่งเพลงเลือกได้สามระดับ Easy Normal Hard

{{< figure src="https://i.imgur.com/aKFDkRn.jpg" >}}

แล้วก็สามารถปรับความเร็วของตัวโน้ตได้

{{< figure src="https://i.imgur.com/HdhtfnA.jpg" >}}

โดยตัวเกมส์จะมีเนื้อเรื่องแฝงอยู่ด้วย แต่แรกจะมีนักเปียโนแค่คนเดียว ในทำนองที่ว่าเดียวดายหน่อยๆ แต่พอเราเล่นไปสักพัก อยู่ๆก็จะมีเด็กสาวตัวน้อยตกลงมาจากหน้าต่าง เราจึงมีหน้าทีต้องพาเด็กคนนี้กลับ จึงปลูกต้นไม้ ซึ่งต้นไม้นี้จะโตขึ้นเรื่อยๆทุกครั้งที่เราเล่น (ต้นไม้ในภาพบน อันนี้เล่นไปจนจบแล้วต้นเลยดูใหญ่นะครับ)

ผมก็ไม่รู้นะว่าเนื้อเรื่องที่ผมเข้าใจจะถูกหรือเปล่า แต่ก็พยายามปะติดปะต่อเรื่องราวกัน

{{< figure src="https://i.imgur.com/bRi5mgl.jpg" >}}

ตัวเกมส์เราสามารถเดินไปห้องอื่นก็ได้ แล้วกดในจุดต่างๆก็จะมีข้อความออกมาให้เราอ่าน บางครั้งถ้าเรากดไปกดมา เราอาจจะเจอเพลงที่ซ่อนอยู่ด้วย เพราะบางครั้งผมไปกดเล่นๆ ปรากฏได้เพลงเพิ่มมาเฉยเลย ก็ลองกดๆแต่ละจุดดู เผื่อจะได้เพลงเพิ่มขึ้นมา ซึ่งความจริงนอกจากจะปลดล็อกเองแล้วไปเจอเพลงซ่อนอยู่ มันก็ยังสามารถซื้อได้ด้วย ที่เจอตอนนี้มีให้เลือกสองแพ็ก แต่ยังไม่ได้ลองซื้อเลย

{{< figure src="https://i.imgur.com/3Ligq6z.png" >}}

เกมส์มันจะจบก็ต่อเมื่อต้นไม้ที่เราปลูกสูง 20 เมตร ซึ่งก็เล่นกันเหนื่อยเหมือนกัน ผมเล่นทุกวันใช้เวลาประมาณสองสัปดาห์เห็นจะได้ ก็พึ่งเล่นจบเมื่อวานพอดี พอเล่นจบปุ๊ปก็จะขึ้น END Credit ให้ เพลงตอนจบนี้เพราะมาก อยากจะหาโหลดเก็บไว้เลย

{{< figure src="https://i.imgur.com/IvvGMQE.jpg" >}}

อันนี้พอดูเครดิตจนจบมันก็ขึ้นภาพนี้มาให้แล้วมีคำว่า “To Be Continued” ซึ่งผมก็เลยงงว่า เอ๊ะ! แล้วมันจะมีต่อยังไง หรือจะให้เราซื้อเวอร์ชั่นต่อไปหรอ อันนี้ก็เลยรอผู้รู้หรือข่าวมาให้เราทราบกันต่อ

เกมส์นี้ดูเนื้อเรื่องแต่งๆมโนๆกันอย่างนี้ แต่มีแว่วกันมาว่าเป็นเกมส์ที่สร้างจากเนื้อเรื่องจริง ซึ่งเพื่อนผมไปเจอมาใน Youtube คลิปเพลง Wing of Piano เนื้อเรื่องมันจะประมาณนี้นะครับ เล่านิดๆ

ก็คือเกมส์นี้สร้างจากเนื้อเรื่องจริงของโรงพยาบาลแห่งหนึ่งที่ไต้หวัน โดยถ้าเอาตัวเลขปริศนาในเกมส์มาใส่เป็นพิกัด GPS แล้วจะบอกเป็นตำแหน่งของโรงพยาบาลแห่งนั้น เป็นเรื่องราวของเด็กผู้หญิงคนนึงที่ประสบอุบัติเหตุทางรถยนต์แล้วมีอาการความจำเสื่อมขึ้นมา เกมส์นี้ถูกสร้างจากจินตนาการของเด็กสาวคนนั้นโดยนักเปียโนปริศนาก็คือคุณหมอที่ดูแล ส่วนตัวละครที่สวมหน้ากากอยู่ก็คือพยาบาล ถ้าลองกดดูที่หน้าต่างของห้องที่มีตุ๊กตาแมวอยู่ จะได้ยินเสียงคลื่นหัวใจ

{{< figure src="https://i.imgur.com/P7iV4Y0.png" >}}

ตัวเลขปริศนาจะเห็นในห้องสมุด ห้องฝั่งซ้ายน่ะ ลองกดดูที่ชั้นหนังสือฝั่งขวามันจะโชว์ขึ้นมา แต่ตอนนี้ผมเจอแค่เลขชุดแรกส่วนชุดที่สองยังหาไม่เจอ

{{< figure src="https://i.imgur.com/yDzbV3x.jpg" >}}

ส่วนเรื่องเสียงคลื่นหัวใจเมื่อกดที่หน้าต่างผมก็พยายามแล้วแต่ก็ไม่เห็นได้ยินเลย ก็เลยงงๆอยู่ แต่เนื้อเรื่องเหมือนจะเข้าเค้าเมื่อมีเพลงนึงโผล่ขึ้นมา Pulse หน้าปกเพลงตามด้านบนเลย ภาพค่อนข้างจะสื่อความหมายตรงตามที่มีคนพูดถึงเนื้อเรื่องที่แท้จริง ซึ่งตอนนี้ผมก็เลยไม่รู้จะเชื่อดีไหม เลยกะไปลองหาข้อมูลเองก่อน (ใครมีข้อมูลก็มาฝากบ้างก็ได้นะครับ)

ก็แนะนำให้ลองไปโหลดกันมานะครับ มีทั้งใน iOS และ Android

iOS : เสียเงินครับ ราคาแค่ 1.99$ หรือประมาณ 60 บาท กว่าๆเท่านั้นเอง

Android : เป็นแปป Demo ครับ ให้โหลดมาเล่นฟรีก่อน แต่จะ Retry เพลงไม่ได้ เพลงบางเพลงเวลาจะกดเล่นจะบังคับให้เรารอประมาณหนึ่งนาทีก่อนเล่นได้ อีกอย่างก็คือความสูงของต้นไม้จะไม่เกิด 3 เมตร ซึ่งก็กดซื้อของแท้ได้ในราคาเท่ากับ iOS ครับ 60 บาทเท่านั้นเอง สามารถกดซื้อจากในตัวเกมส์ได้เลย

ลองเล่นดูแล้วจะไม่ผิดหวังครับ 60บาท ถือว่าเป็นการให้กำลังใจนักพัฒนาทั้งหลายละกัน อีกอย่างนะครับ แนะนำให้ใส่หูฟังเล่น เพราะมันจะอินกับเพลงมากตอนเล่น ตอนนี้ก็เลยแนะนำเพื่อนไปสามถึงสี่คนละ แต่ละ คนก็ชอบทั้งนั้นเลย ถ้าถามว่าให้คะแนนจากเต็มห้าเท่าไหร่ ก็คงต้องบอกว่าเกมส์นี้รับไปเลยห้าคะแนนเต็มๆ
