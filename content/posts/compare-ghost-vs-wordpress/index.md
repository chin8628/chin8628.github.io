ปิดเทอม เพื่อนหลายคนไปเรียนต่างประเทศกันเยอะ นี่เลยชวนๆให้เอาประสบการณ์ไปเรียนต่างประเทศนะ เขียนลงบล็อกเผื่อเผยแพร่ให้คนอื่นได้อ่านกัน ส่วนใหญ่คำถามที่ตอบกลับมาคือ เขียนลงอะไร exteen ไหม ซึ่งผมก็แน่นำ Wordpress ไปง่ายดี แต่หลายครั้งก็เสริมๆให้ลอง Ghost ด้วย ซึ่งร้อยละร้อยถามกลับมา "ต่างกันไง" โดนถามหลายรอบมาก รอบนี้เลยเขียนสรุปตามความเห็นของตัวเองละกัน (ไม่ใช่อะไร เผื่อมีคนถามอีกขี้เกียจตอบ กะโยนบล็อกให้อ่านเลย....)

## Wordpress `สะดวก ออปชั่นเยอะ`

{{< figure src="https://i.imgur.com/TBMyhoT.png" >}}

Wordpress เป็นแพลทฟอร์มบล็อกที่คนนิยมโดยเสียส่วนมาก เพราะใช้งานง่าย สะดวก ปลั๊กอินเยอะมาก คุณต้องการอะไร มันมีให้หมดแล้วแค่อาจจะต้องโหลดเพิ่ม ทำอะไรก็ทำได้ เว็บเล็กๆ ยัน เว็บบริษัท นอกจากนั้นคือกลุ่มสังคมของคนใช้ Wordpress นั้นกว้างมาก หากคุณมีปัญหาอะไร เซิร์ชใน Google ได้เลย ไม่มีทางที่ปัญหาที่คุณเจอคนอื่นจะยังไม่เจอแน่นอน หรือเข้าไปถามตามกลุ่มในเฟสบุ้คก็ได้ ต้องมีแน่นอน

ลักษณะของ Wordpress คือ คุณเข้าไปที่เว็บของคุณ แล้วก็เขียนบทความตามใจชอบ ใส่ภาพใส่วิดีโอ อัพภาพเข้าบทความทำได้หมด เพราะ Wordpress มีระบบที่รองรับงานเขียนของคุณได้หมด ตัวหนาตัวบางตัวเอียง เปรียบเทียบคงจะบอกได้ว่าเหมือนเขียนงานใน MS Word ส่วนพวกสื่อภาพวิดีโอ Wordpress ก็สามารถให้คุณอัพไฟล์ของคุณขึ้นไปได้แล้วนำใส่บทความ พูดง่ายๆคือ ระบบจัดการสื่อและระบบที่ไว้เขียนงานครบครันมาก

ซึ่งสำหรับคนเริ่มเล่นก็เหมาะเลย เพราะสามารถลงทะเบียนและใช้งานได้ทันที ([Wordpress.com](https://wordpress.com/))

หรือบางคนไฮโซหน่อย มีเซิร์ฟเวอร์ของตัวเองก็สามารถไปโหลดได้ที่ ([Wordpress.org](https://wordpress.org/))

#### เหมาะกับใครบ้าง?

*   อาจารย์ที่ต้องการทำสื่อการเรียนการสอนให้เด็ก
*   หน่วยงานหรือธุรกิจที่ต้องการเผยแพร่ข้อมูลของตน
*   คนทั่วไปที่อยากบ่นยาวมาก บ่นเป็นบทความวิพากษ์วิจารณ์
*   ใครก็ตามที่อยากเขียนบล็อกแต่ไม่ต้องการเสียเงินเพิ่มอีกแล้ว (เรื่องเงินสำคัญ (ฮา)

## Ghost `เน้นเรียบง่าย ไม่เยอะ`

{{< figure src="https://i.imgur.com/XDB9a3I.png" >}}

Ghost เป็นระบบแพลทฟอร์มบล็อกตัวใหม่ เข้าใจว่าเป็นทีมงานช่วงก่อตั้ง Wordpress แยกตัวออกมาตั้งทีมใหม่เพราะมองว่า wordpress นั้นใหญ่เกินไปกว่าที่จะเป็นแค่บล็อก

Ghost นั้นต่างจาก Wordpress ลิบลับ เพราะถ้าเทียบเป็นคน Wordpress คือคนที่อู้ฟู้ไฮโซมีทุกอย่างครบครันผู้คนรายล้อม แต่ Ghost เป็นคนที่สมถะ ไม่ขออะไรมากชีวิตติดดิน เพราะอะไร? เพราะถ้าคุณได้ลองเข้าไปใช้ Ghost แล้วคุณจะรู้เลยว่ามันเรียบง่ายมาก ออกแบบมาเพื่อแค่เป็นบล็อกเลยจริงๆตามคำโปรยของโปรเจกต์ "Just a blogging platform"

ความสามารถของ Ghost มีแค่เขียนบล็อกได้... แค่นั้นแหละครับ มันไม่สามารถอัพโหลดภาพหรือสื่อใดๆเข้าไปเก็บในบล็อกได้เลย ต้องใช้วิธีอัพไปฝากที่อื่นแล้วเอา URL ของภาพมาแทน ส่วนเรื่องการใส่สไตล์ให้ข้อความก็ไม่ได้มีปุ่มกดให้คลิ๊กๆแบบ Wordpress แต่เป็นลักษณะของการใช้เครื่องหมายกำกับแทน เช่น คุณต้องการพิมพ์ตัวหนา ให้นำ \* ไปใส่หน้าและหลังข้อความนั้น เป็นต้น

ความสามารถอื่นๆของ Ghost ก็คือแต่งรายละเอียดโปรไฟล์ของผู้เขียนได้ ใส่แท็กให้บทความได้ เปลี่ยนธีมของบล็อกได้ (แต่ธีมตอนนี้ยังไม่หลากหลายเท่า Wordpress) ประมาณนั้นแหละครับ

หลายคนอาจจะสงสัย "เห้ย แล้วมันจะไปมีคนใช้หรอ ทำอะไรก็ไม่ได้เลย" ก็ไม่รู้สินะ แต่ผมใช้คนนึง (บล็อกนี้เขียนด้วย Ghost) แต่ก็เหมือนจะมีคนใช้เพิ่มขึ้นมาเรื่อยๆ ก็อย่างที่บอก จุดเด่นของมีคือ "ก็เป็นแค่บล็อก" ทำให้ Ghost เป็นเหมือนแหล่งหลบพักของคนที่หนีความวุ่นวายจากเมืองใหญ่อย่าง Wordpress มาหาวิถีชีวิตเรียบง่ายธรรมดาแบบ Ghost

แต่**ข้อเสีย**จุดใหญ่เลยคือ มันเสียตังค์ครับ... ลองไปดูค่าใช้จ่ายได้ใน [ghost.org/pricing](https://ghost.org/pricing/) ได้ครับ ซึ่งความจริงมันก็มีแบบฟรีนะครับ ก็คือให้ไฟล์ซอร์สโค้ดของ Ghost ไปเลย อะคุณโหลดไปเองเลย แต่คุณต้องไปหาเซิร์ฟเวอร์หรือคอมที่ต้องเปิดให้ Ghost ทำงานตลอดเวลาแค่นั้นเอง ซึ่งก็โชคดีผมมีเซิร์ฟเวอร์ของผมอยู่แล้วก็เลยสบายไป

#### เหมาะกับใครบ้าง?

*   ฮิปสเตอร์ที่ต้องการนั่งร้านกาแฟจิบลาเต้อุ่นๆแล้วเขียนบล็อกเรื่องราวชีวิต
*   นักปรัชญาและนักเขียนที่ขอแค่เขียนเผยแพร่ความคิดแค่นั้น เช่นคุณวินทร์ เลียววาริณ เป็นต้น
*   นักพัฒนา Ghost //คือพัฒนาแล้วควรจะใช้ด้วย
*   คนทั่วไปที่เบื่อกับอะไรที่เยอะๆอย่าง Wordpress แล้วบังเอิญคุณไม่รวยก็มีเซิร์ฟเวอร์เป็นของตัวเอง เป็นต้น

สำหรับคนที่คิดว่า "เอ๊า!? แล้วถ้าอยากใช้ Ghost จนจะลงแดงตายแต่ไม่อยากเสียเงินและไม่ได้เป็นโปรแกรมเมอร์มีเซิร์ฟเวอร์เป็นของตัวเองละทำไง" ผมก็มีคำแนะนำว่าให้ทำตัวเป็นลูกแมวน้อยไปออดอ้อนคนมีเซิร์ฟเวอร์ให้ลงให้ใช้ให้หน่อยครับ...

โดยส่วนตัวผมใช้ Ghost และชื่นชอบมากกว่า Wordpress เพราะใช้ Wordpress มาหลายปีแล้วก็เบื่อๆกับความเยอะเกินของมันเลยมาอยู่กับ Ghost เพราะเรียบง่ายสบายตาดีครับ

สุดท้าย... ขอบคุณสำหรับทุกท่านที่เข้ามาอ่านครับ

ปล. สำหรับคนอยากเห็นหน้าสำหรับเขียนบทความใน Wordpress ให้ไปลองเซิร์ชใน Google ว่า "wordpress new post" นะครับ พอดีผมไม่มีภาพ
