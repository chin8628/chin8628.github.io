เกริ่นก่อนครับ... เรียกว่าให้ความรู้อันน้อยนิดมากๆ เพื่อจะได้ด่าและแซะขนมชนิดนี้ถูกต้อง

Croissant เรียกบ้านๆก็คือ "ครัวซองค์" บ้านเกิดอยู่ฝรั่งเศส แต่หลายร้อยปีต่อมาก็เห็นวางขายชิ้นละ 25 บาท ตามตลาดทั่วไปจนนึกว่าขนมไทย อันที่จริงคือ ขนมไทยหายากกว่าครัวซองค์อีก

ต่อมาคือ Taiyaki เรียกทั่วไปก็ "ไทยากิ" ต้นกำเนิดมาจากญี่ปุ่น เป็นขนมรูปปลา ยัดใส่ด้านใน เวลากินก็กัดเข้าไปเจอไส้(ปลา) เยิ้มออกมา ไส้ด้านในก็เป็นพวกคัสตาร์ด, ถั่วแดง, ถั่วหวาน เป็นต้น

ญี่ปุ่นกับฝรั่งเศสห่างกันครึ่งโลก แต่ก็ไม่เข้าใจว่าทำไมถึงเอาชื่อขนมสองประเทศมารวมกัน? แต่เรื่องชื่อก็เรื่องนึง เพราะนี่ตอนกินไม่ได้สนใจชื่อเลย ได้มาก็กินเลย และนี่ก็คือขนม Croissant Taiyaki

{{< figure src="https://i.imgur.com/zpiToWi.jpg" >}}

ปกติแล้วจากที่เคยพบเห็น ไทยากิจะมีลักษณะเป็นขนมรูปปลาตามที่กล่าวไว้ ซึ่งคุณเข้าใจคำว่ารูปปลาใช่ไหม มันต้องตัดมาเป็นตัวปลาเลย ตอนผมได้ยินว่าไทยากิ ผมก็เข้าใจว่ามันจะเป็นแบบที่เราเห็นตามอนิเมะ หรือซีรี่ย์ญี่ปุ่นอะไรนั่น แต่พอได้เจอของจริง คุณก็ต้องอึ้ง!

{{< figure src="https://i.imgur.com/zawZbXC.jpg" >}}

คือแบบ... เอาขนมสี่เหลี่ยมยัดไส้แล้วปั๊มรูปปลาชัดๆ ตัดขอบหน่อยให้สวยงามไม่ได้หรอ? หรือกลัวลูกค้าเสียดายไปคุ้ยเศสขนมกินในถังขยะของร้าน แต่ก็ช่างมัน เพราะคิดว่า อ่า! นี่อาจจะเป็นการทำไทยากิสไตล์ฝรั่งเศสก็เป็นได้!

อย่างที่เห็น ตัวแป้งของขนมจะมีเกล็ดสี่เหลี่ยมๆรอยรอบขนม มันคือเกล็ดน้ำตาลครับ โดยรวมเกล็ดน้ำตาลอร่อยกว่าขนม คือตอนเคี้ยวเจอเกล็ดน้ำตาลนี่เพลินนะ กรุ่บๆกรอบๆ

### ชิ้นแรก ไส้คัสตาร์ด(เย็น)

{{< figure src="https://i.imgur.com/8Zi5ORC.jpg" >}}

คำว่า "เย็น" หลังชื่อผมไม่ได้เติมเองนะ คือเห็นแม่(คือแม่เป็นคนซื้อ ไม่ใช่ผม) บอกว่ามันเขียนชื่อไส้ที่ร้านว่า "คัสตาร์ดเย็น" อย่างงี้จริงๆ นี่ก็คิดเล่นๆว่า ถ้าเอาไปตากแดดประเทศไทยสักครึ่งชั่วโมงมันต้องเปลี่ยนชื่อเมนูเป็น "คัสตาร์ดร้อน" ไหม

รีวิว: แป้ง! เป็นแป้งครัวซองค์เลย ซึ่งจากความมโนส่วนตัวของตัวเอง เข้าใจว่าไทยากิ แป้งจะเป็นอีกแบบ แบบนุ่มๆ คิดว่านี่แหละคือการผสมกันของครัวซองค์และไทยากิ (นอกเรื่องยาว) สรุปเรื่องแป้งคือ เป็นแป้งแบบครัวซองค์กรอบๆบางๆ ตัวแป้งรสชาติอร่อยดี

เข้าสู่เรื่องเนื้อใน ไส้! ไส้คัสตาร์ดไม่หวานเลี่ยนแบบพวกขนมทั่วไป รสชาติอ่อนๆกำลังดี แต่คนชอบหวานเลี่ยนอาจจะไม่ชอบ

### ชิ้นสอง ไส้ถั่วแดง

{{< figure src="https://i.imgur.com/uyI8H6x.jpg" >}}

(อยากจะบอกว่า ที่เห็นแต่ละภาพไส้มันเยิ้มๆ ไม่ใช่ว่าไส้มันเยอะนะ นี่บีบขึ้นมาให้มันถ่ายเห็นไส้)

รีวิว: ตามสไตล์ถั่วแดงทั่วไป ก็เป็นถั่ว(ผิด) ก็รสชาติไม่หวานเกิน ไม่จืดเกิน เอาจริงๆคือเหมือนจะหวานน้อยกว่าขนมปังสอดไส้ถั่วแดงของฟาร์มเฮ้าส์เสียอีก ดูดไส้เข้าไปมีคงเหลืออารยธรรมของถั่วที่ยังเป็นเม็ดๆอยู่บ้าง แต่ก็น้อยเต็มทน โดยรวม อร่อยกว่ารสคัสตาร์ดเย็น เพราะไม่หวานเท่า สำหรับคนชอบหวานน้อยถึงไม่หวานเลย แนะนำไส้นี้

### สรุป

*   ไส้คัสตาร์ด เหมาะสำหรับคนชอบหวาน แต่ก็ไม่ได้หวานมากจนเลี่ยน
*   ไส้ถั่วแดง เหมาะสำหรับคนไม่ชอบหวาน อยากกินอะไรที่มันเจแปนๆ
*   **ไม่เหมาะเลย** สำหรับคนที่อยากลดความอ้วน เพราะจากทั้งแป้ง น้ำตาล และไส้ด้านใน อ้วนแน่นอน!
